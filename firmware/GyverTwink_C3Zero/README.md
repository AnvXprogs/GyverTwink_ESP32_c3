# GyverTwink для ESP32-C3 Zero

Это отдельная версия прошивки, перенесённая с ESP8266. Оригинальный `GyverTwink_v1.2` не изменён.

## Сборка

- Плата в Arduino IDE: **ESP32C3 Dev Module** (пакет **esp32 by Espressif Systems**).
- Нужны **FastLED 3.9 или новее**, **EncButton 3.x** и **EEManager**. В репозитории лежит FastLED 3.4.0 и EncButton 1.15; обе версии слишком старые для этого скетча. Обновите FastLED и EncButton через Library Manager. Для EEManager используйте версию из `libraries/EEManager` этого репозитория: в ней добавлена фиксация EEPROM для ESP32.
- Откройте `GyverTwink_C3Zero.ino` и соберите скетч.

## Подключение

- `GPIO4` — DATA внешней WS2812 ленты.
- `GPIO3` — кнопка между GPIO3 и GND.
- Общая земля ESP32 и блока питания ленты обязательна. Питайте ленту отдельным блоком 5 В; не подавайте её питание от платы.
- Для надёжного сигнала DATA используйте преобразователь уровня 3,3 → 5 В (например, 74AHCT125).
- На C3 Zero встроенный адресный светодиод подключён к GPIO10; для внешней ленты этот пин не выбран.

При необходимости измените `BTN_PIN`, `LED_PIN`, `LED_TYPE`, `LED_ORDER` и `LED_MAX` в начале скетча.

Настройка Wi-Fi выполняется локальным порталом этой версии по адресу `192.168.1.1`. Сеть точки доступа называется `ESP Config`.
